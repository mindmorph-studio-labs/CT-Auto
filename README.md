# CT-Auto

Plateforme moderne de démarches automobiles et annuaire de professionnels agréés.

## 🚀 Fonctionnalités

- Guichet unique d'orientation pour les démarches automobiles
- Annuaire de professionnels agréés géolocalisés
- Guides pratiques optimisés SEO
- Calculateur de prix de carte grise
- Système de génération de leads

## 🛠️ Stack Technique

- **Framework** : Next.js 15 (App Router)
- **Langage** : TypeScript
- **Styling** : Tailwind CSS + shadcn/ui
- **Base de données** : Prisma ORM
- **Validation** : Zod + React Hook Form

## 📦 Installation

```bash
# Cloner le dépôt
git clone https://github.com/VOTRE_NOM/CT-Auto.git

# Installer les dépendances
npm install

# Configurer l'environnement
cp .env.example .env

# Lancer le serveur de développement
npm run dev
